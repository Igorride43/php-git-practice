# Library Management System

Учебное PHP-приложение для управления библиотекой.

## Функции

- Добавление книг.
- Удаление книг.
- Поиск по названию.
- Вывод списка книг.
- Проверка доступности экземпляра.
- Регистрация читателей.
- Выдача и возврат книг.

## Запуск

Из корня репозитория:

php library/index.php
php library/test_user.php
